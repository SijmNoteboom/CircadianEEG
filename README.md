# CircadianEEG
EEG sleep staging based on circadian rhythm

# Getting started

## Clone the repository

`git clone (https://github.com/SijmNoteboom/CircadianEEG.git)`

## Install dependencies

```
cd .\CircadianEEG\
python -m venv venv # optional
pip install -r .\requirements.txt
```

## Use the tool:

```
python main.py 
```
